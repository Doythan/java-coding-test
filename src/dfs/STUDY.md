# DFS (Depth First Search)

## 개념
- 그래프나 트리를 탐색하는 가장 기본적인 방법
- 한 방향으로 끝까지 들어갔다가 더 이상 갈 수 없으면 되돌아온다
- 재귀 또는 스택을 사용한다

## DFS 기본 템플릿 (인접 리스트)

``` java
static void dfs(int v) {
    visited[v] = true;

    for (int next : graph[v]) {
        if (!visited[next]) {
            dfs(next);
        }
    }
}
```

## DFS 핵심 규칙 3가지

방문 체크를 먼저 한다

재귀 호출 전에 조건 검사

되돌아온다는 개념을 이해한다

👉 이 중 하나라도 빠지면 무한 루프 or StackOverflow 발생

## DFS를 쓰는 대표적인 상황

모든 경우의 수 탐색

연결 요소 개수 구하기

섬 개수 / 영역 크기

경로 존재 여부 판단

백트래킹 (조합, 순열, 부분집합)

## DFS 특징 요약

깊이 우선

구현 간단

최단 거리 보장 ❌

경우의 수 탐색에 강함

## 주의 사항 (실전에서 많이 터지는 부분)

재귀 깊이가 깊어질 경우 StackOverflow 가능

방문 처리 위치 실수하면 결과 완전히 틀림

DFS로 최단 거리 구하려고 하면 안 됨

## DFS vs BFS 한 방에 정리

| 구분 | DFS | BFS |
|----|----|----|
| 탐색 방식 | 깊이 우선 | 너비 우선 |
| 자료구조 | 재귀 / 스택 | 큐 |
| 최단 거리 | ❌ | ✅ |
| 경우의 수 | ✅ | ❌ |
| 메모리 | 적음 | 큼 |

## 문제에서 이렇게 나오면 바로 선택

- "최단", "최소", "몇 번 만에" → **BFS**
- "모든 경우", "가능한지", "개수" → **DFS**
- 2차원 배열 + 거리 → **BFS**
- 백트래킹 냄새 → **DFS**
