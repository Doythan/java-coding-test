# Java Coding Test Preparation

Java로 코딩 테스트를 대비하기 위한 개인 학습 레포지토리입니다.  
정렬, 탐색, 자료구조, 그리디, DP 등 **코딩 테스트 핵심 알고리즘을 단계별로 정리**하고
직접 Java 코드로 구현하며 실력을 축적하는 것이 목적입니다.


## 학습 목표
- Java 기반 코딩 테스트 문제 해결 능력 강화
- 알고리즘 유형별 핵심 패턴 체계화
- DFS/BFS, 정렬, 탐색 등 빈출 알고리즘 템플릿 확보
- 문제 접근 → 구현 → 정리까지 한 사이클로 학습

## Commit Rule
- `feat:` 새로운 알고리즘 또는 문제 추가
- `refactor:` 코드 개선
- `docs:` 문서 정리
